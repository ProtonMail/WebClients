# Border

Utility classes for controlling an element's borders. A border utility applies a `1px` border with the `--border-norm` color by default.

## Placement

`border` applies a border on every side. `border-top`, `border-right`, `border-bottom` and `border-left` apply a border on a single side. `border-none` removes all borders.

## Color

`border-primary`, `border-norm`, `border-weak`, `border-danger`, `border-warning`, `border-success`, `border-info` and `border-currentColor` change the border color. Use them together with a placement class.

## Style

`border-dashed` and `border-dotted` change the border style. The style applies only to the sides the placement class enables — e.g. `border-bottom border-dashed` dashes the bottom border only.
